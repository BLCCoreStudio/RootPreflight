# RootPreflight

> **Project status: sunset / discontinued.**

BLCCoreStudio has decided to end active development of RootPreflight as part of a deliberate reduction in project count and maintenance load.

RootPreflight was an early research prototype for inspecting Magisk, KernelSU and APatch-style module metadata before installation. It never reached a complete Android application or end-to-end scanner.

**No further feature development or routine maintenance is planned.** The repository is being kept temporarily as a historical research snapshot and may later be made private or removed.

## Historical source

The earlier Kotlin core model, conflict-detection foundation and original research direction remain available through the Git history.
